### **Описание**

Динамическая библиотека **<ins>Photon Big Math</ins>** (сокращённо PBM) это высокопроизводительная библиотека для работы с большими числами. Она предоставляет эффективные алгоритмы для операций с длинной арифметикой, включая сложение, вычитание, умножение, деление, возведение в степень и модульные вычисления.
Изначально она создавалась для языка <a style="color:#f7d619" href="https://github.com/Trimo-inc/Photon">photon</a>.
 

### **Элементы документации**
В документации вы можете встретить такие слова, как `${NotNull}`, `${Dynamic}`, `${Nullable}`, `${Dynamic | Nullable}`,  и другие. Это специальные обозначения для программистов, использующую данную библиотеку, сейчас я вам подробнее о них расскажу.
- **${NotNull}** — указатель не равен _NULL_. Вы можете это увидеть в описаниях структур `pbm_Natural_ptr`, `pbm_BigInteger_ptr`, `pbm_BigDecimal_ptr`. Этот символ означает, что объект с таким типом не должен (хотя может) быть равным _NULL_. Он специально указывается в многих функциях, чтобы внутри них не проверять структуру на _NULL_, так как это может снизить <span style="color:#5D9B9B;">производительность</span>.
	Тут скрывается суть этого символа, если вы видите в документации к функции, что она имеет параметр с _${NotNull}_, но вы передаёте занулённое значение (_NULL_), то у вас будет **неопределённое поведение**. 
```c
pbm_Natural_ptr my = NULL;
pbm_pbm_natural_default_init(my); // Ошибка: обращение по нулю

```
- **${Dynamic}** — означает, что объект динамический, то есть он выделен в куче, и после его использования вам нужно будет его освободить (чтобы не было утечки памяти). В структурах **pbm** используются специальные функции, в других случаях используйте _free(...)_
```c
// Безопасно создаём строку:
pbm_Natural_ptr ibig = _pbm_natural_create("1000000000000000", 10);

_pbm_natural_delete(pbm_Natural_ptr ibig); // НЕ используем free!
```

### **Использование**
Прежде всего вам нужно включить библиотеку в ваш `CMakeLists.txt`:
```cmake
target_link_libraries(${PROJECT_NAME} PRIVATE PBM)
```

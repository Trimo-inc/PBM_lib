### <b><a class="brief" style="color:#baa4fc;">Описание</a></b></br>
Динамическая библиотека <b><ins>Photon Big Math</ins></b> (сокращённо PBM) это высокопроизводительная библиотека для работы с большими числами. Она предоставляет эффективные алгоритмы для операций с длинной арифметикой, включая сложение, вычитание, умножение, деление, возведение в степень и модульные вычисления.
Изначально она создавалась для языка <a style="color:#f7d619" href="https://github.com/Trimo-inc/Photon">photon</a>.

### <b>Использование</b>
Прежде всего вам нужно включить библиотеку в ваш `CMakeLists.txt`:
```cmake
target_link_libraries(${PROJECT_NAME} PRIVATE PBM)
```

## PBM - PhotonBigMath library


### English language:
- __Description__:</br>
<ins>Photon Big Math</ins> library (abbreviated PBM) is designed to work with large numbers and their representation in different number systems, as well as operations on numbers: addition, subtraction, multiplication, division.

- Created in C

### Russian language:
- __Описание__:</br>
Библиотека <ins>Photon Big Math</ins> (сокращённо PBM) предназначена для работы с большими числами и их представление в разных системах счисления, а также операции над числами: сложение, вычитание, умножение, деление.

- Создана на Си
